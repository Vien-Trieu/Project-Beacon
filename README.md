# Testing Report Portal

External web portal for viewing breaker testing reports.

## Users

- External customers
- Internal employees

## Public functionality

Customers can access an individual testing report through a permanent QR-linked URL without authentication.

## Employee functionality

Authenticated employees will be able to search and manage testing reports.

## Frontend

- React
- TypeScript
- Vite

## Development

Install dependencies:

npm install

Start development server:

npm run dev
